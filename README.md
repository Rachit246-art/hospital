# Nexora International Hospital 🏥✨

A luxury contemporary medical center website built with an emphasis on architectural aesthetics, smooth micro-interactions, dark telemetry innovation theater, and complete cross-device responsiveness.

## ✨ Features
- **Hero Parallax & Live Metrics**: Dynamic visual presence with high-impact key statistics.
- **Auto-Sliding Specialties Carousel**: Comprehensive medical department navigation with smooth looped sliding and touch-drag support.
- **Medical Innovation Theater**: Dark luxury UI (`#070B16`) featuring real-time clinical telemetry, robotic surgery (DaVinci Xi 0.1mm precision), and biotelemetry monitoring.
- **7-Star Sovereign Patient Care**: Luxury inpatient suites with iPad controls, private family terraces, and dedicated medical teams.
- **Healing Architecture**: Interactive spatial hotspots illustrating biophilic walls and circadian lighting.
- **Renowned Medical Faculty**: Top specialist profiles with Harvard, Oxford, and Hopkins credentials, verified ratings, and one-tap appointment booking.
- **24/7 Level 1 Emergency Strip**: Direct hotline dispatch with a pulsating radar beacon.
- **Multi-Device Responsive System**: Multi-tiered CSS media system tailored for mobile (320px–480px), tablet (768px), and desktop (1024px+).

## 🚀 Technologies Used
- HTML5 (Semantic Structure & Accessibility)
- Vanilla CSS3 (Custom design system, Glassmorphism, CSS Grid & Flexbox)
- Vanilla JavaScript (Intersection Observer, Parallax scrolling, Interactive modals & Hotspots)

## 💻 Local Setup & Running
1. Clone the repository:
   ```bash
   git clone https://github.com/Rachit246-art/hospital.git
   cd hospital
   ```
2. Open `index.html` directly in any browser or run a local server:
   ```bash
   npx serve .
   ```
3. Visit `http://localhost:3000` in your web browser.
